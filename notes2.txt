Explaination for SuffixArray and qsort_r!!!!
classic example: b a n a n a
qsort_r(
    suffixArr = [0, 1, 2, 3, 4, 5],
    nitems = 6
    size = 4 bytes ( or sizeof(int) )
    compar = cmpSuffix,
    arg = block ( which is "banana" )
)

INSIDE qsort_r:
calls cmpSuffix(suffixArr[0], suffixArr[3], block)
    a = suffixArr[0] (0)
    b = suffixArr[3] (3)
    ctx (context) = "banana" (or whatever the block is)
    compares suffixes:
        "banana" vs "ana"
        this will return a negative value because 'b' < 'a' is not true
process repeats until suffixArr is sorted alphabetically

NOTE: For suffix array speed and size complexity, possibly look at DivSufSort in the future
